Support

How can we help?

For questions, troubleshooting, or help with Just Speak to It, email hello@justspeaktoit.com. You do not need a GitHub account to contact us.

Recording and permissions

If recording cannot start, check that Just Speak to It has microphone permission in your device’s Settings. Apple Speech also needs Speech Recognition permission. If you use a cloud provider, check that its API key is configured and its account has access to the selected model.

Tell us what happened

Include your device model, operating system version, app version, the model or provider you selected, and the steps that led to the problem. If there is an error message, include its text.

Never send API keys, passwords, or private recordings. Remove personal information from screenshots and transcripts before sharing them.

Updates and privacy

Find the current Mac download on the app website. Read our privacy policy for details about local and cloud processing.

Report a reproducible bug

If you prefer GitHub, you can report an issue. GitHub issues are public; use email for private support questions.
