Just Speak to It support

How can we help?

For questions, help getting started, or a problem with the app, email hello@justspeaktoit.com. You do not need a GitHub account to request support.

Recording on iPhone and iPad

Open Just Speak to It and tap the microphone to start recording. Tap it again to finish. Allow microphone and speech recognition access when asked. Apple Speech is available without a provider account or API key; on-device support depends on your device and language.

If recording will not start, open iOS Settings, find Just Speak to It under Apps, and check its microphone and speech recognition permissions. You can also find these permissions under Privacy & Security. Check the selected model in the app's Settings before trying again.

Cloud providers and API keys

Cloud transcription and optional text processing use the provider you select. Enter that provider's API key in the app's Settings. If a provider reports an authentication or balance error, check the key, permissions and available credit with that provider. You can switch back to Apple Speech for transcription without a cloud API key.

Help us understand the problem

Tell us your device model, operating-system version, app version, selected transcription model, the steps you took and the exact error message. A screenshot can help.

Never send API keys, passwords, or private recordings and transcripts. Remove personal information from screenshots before sharing them.

If you prefer, you can also report a bug on GitHub. GitHub reports are public, so include only information you are comfortable sharing.

Privacy questions

Read our privacy policy for details about recordings, transcripts and optional cloud services. For privacy questions or requests, contact hello@justspeaktoit.com.
