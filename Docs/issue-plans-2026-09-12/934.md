## Existing contract to qualify

`TranscriptionRecordingService.clipboardTextAtStop` selects raw text for Copy/Copy & Polish; `applyDestinationSideEffects` calls PolishClipboard.copyRaw once. `startPostProcessing` updates the same History row and guarded latest completion, with no clipboard capability in AutomaticPolishOperation. Empty/History Only creates no clipboard write. A late polish must never overwrite a different, identical or non-text copy made by another app. No ownership-token replacement/retry window or foreground watchdog is authorised here.

Run the existing iOS `TranscriptionRecordingServiceTextTests`, `TranscriptionCompletionTests` and `AutomaticPolishOperationTests` on Apple CI as supporting software evidence, including `testAutomaticDestinationsNeverWritePolishOrRestoreRaw`, out-of-order completion and cancellation/expiration cases. Their presence or mocked success does not satisfy physical UIKit clipboard delivery.

| Scenario | Expected observation |
|---|---|
| Copy, foreground Stop | Immediate paste is the raw transcript, never a polishing placeholder |
| Copy & Polish, foreground then switch apps | Immediate paste is raw; delayed polished text appears in the SAME History row; clipboard remains raw unless the user changes it |
| Different text copied during delayed polish | The different text survives successful polish and a separate failed-polish run |
| Identical raw text copied again during polish | No later automatic polished/raw replacement; explicitly copy a sentinel afterwards if needed to make a later overwrite observable |
| Image/non-text content copied during polish | Content/type survives success, failure and background transition; inspect by paste into a compatible app |
| Hardware/intent or locked Stop, then unlock | Actual paste and saved History outcome are observed; do not treat read-back alone as delivery proof |
| History Only and empty capture | Existing clipboard content is preserved; successful History row/output follows current destination policy |
| Cancel recording B while A polishes | A's History polish may complete, B does not cause A to rewrite clipboard or overwrite a newer latest-completion result |
