How it works

Hold a key, speak, and keep working

Just Speak to It stays in the background while another app is active, so dictating does not pull focus away from your window.

01

Trigger from anywhere

Hold fn, double-tap it, or bind a custom global shortcut. Recording starts while the frontmost app keeps focus.

02

Transcribe and apply rules

Stream words live as you speak or transcribe a saved audio file. Personal corrections, pronunciation hints and per-app profiles adjust the model and clean-up prompt for code, chat or email.

03

Insert where you started

The session records the active text field before capture begins and types the result back into it, even if another window came forward mid-sentence. Clipboard output is optional and restores the previous clipboard afterwards.

Privacy and keys

No middleman server

Audio stays on the device when a local model runs, and goes straight to the chosen provider when a cloud key is configured. Just Speak to It runs no relay server and requires no account.

Local models run offline

Mac builds include Apple's on-device speech recognisers, six WhisperKit models on Core ML, and Parakeet for local streaming. Windows and Linux betas run whisper.cpp locally. Clean-up can use Apple Intelligence, downloaded local LLMs or offline rules.

Cloud providers use your keys

Cloud transcription, clean-up and speech synthesis use accounts you control. Keys live in the system credential store, and requests go directly to each provider (or through an optional local Azure proxy on your Mac).

Private history and opt-in telemetry

History stays on the device unless synced through a private iCloud container. Crash diagnostics and optional Mac usage analytics exclude audio, transcripts and keys.

Apple's older Speech Recognition engine can fall back to Apple's servers when an on-device model is unavailable, and enabling iCloud sync or cloud providers sends data off the device. Read the privacy policy for the full breakdown.

iPhone & iPad

Hands-free capture from the Lock Screen

Start recording from a hardware press or Control Centre, check progress in the Dynamic Island, and send finished text to the clipboard or your Mac.

  • Action Button, Control Centre and SiriStart or toggle capture without opening the app. The Dictate Shortcut action stops automatically after a pause and passes the text to the next step.
  • Live Activity with a Stop controlThe Dynamic Island shows recording state, word count and recent words, with a button that ends the session directly.
  • Configurable outputSet once whether hardware triggers copy raw text, copy and polish, or save quietly to History.
  • Send to Mac via iCloudPhone captures arrive in Mac History through your private iCloud container, with Handoff support and optional paste.

Automation

Scriptable from the terminal, Shortcuts and MCP

Every automation surface talks to the running app, so scripts and coding agents use the configured models and profiles without handling API keys.

Terminal
# Transcribe an audio file to the clipboard
$ speak transcribe memo.m4a | pbcopy

# Dictate a commit message
$ speak listen
$ git commit -m "$(speak stop)"

# Register the MCP server for Claude Code
$ claude mcp add justspeaktoit -- speak mcp

Local socket access stays off until enabled in Settings → General → Automation.

  • CLI (speak) transcribe, listen, stop, history and status, with versioned --json output and distinct exit codes so scripts can branch cleanly.
  • MCP server (speak mcp) Exposes dictation, file transcription and History over stdio to Claude Code and other MCP clients, with idempotent start and stop calls.
  • Shortcuts and URL scheme App Intents on Mac and iOS, plus justspeaktoit:// and x-callback-url actions when the iOS app is in front.
